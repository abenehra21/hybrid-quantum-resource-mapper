Four phases, one pipeline

Give the system an application. It predicts the circuit it would need, checks the transparent rules, asks the learned allocator, and, when the task cannot run as it is, splits it into parts and schedules them on classical nodes and the quantum processor. What is real and what is modelled

Computed for real

  • Every circuit is built and transpiled with Qiskit for the two target topologies.
  • Max-Cut plans are actually solved: each part by enumeration, then merged. The certified ratio is a proof for that instance, not an estimate.
  • Gate cutting is checked numerically: fragments reproduce the uncut expectation value to 1e-14.

Modelled

  • No real quantum hardware is used. Fidelity, shots, run times and energy come from a stated ground-truth model built from published effects (config/environment.yaml).
  • The learned components are shown to recover that model from pre-execution information. Real execution feedback is Phase 5.
  • Chemistry Hamiltonians are synthetic, and one QPU topology is a square-grid stand-in.
